# App Screenshots & Visual Previews

This directory contains visual previews and screenshot assets for **Focentra**.

---

## 📸 Recommended Screenshot Structure

To ensure consistency across GitHub previews, app store listings, and documentation, screenshots should adhere to the following naming conventions and specs:

| File Name | Screen / Feature | Description |
| :--- | :--- | :--- |
| `home.png` / `dashboard.png` | **Dashboard** | Daily focus ring, active streak, subject velocity, and recent sessions |
| `timer.png` | **Timer Screen** | Circular timer ring, countdown/pomodoro mode selectors, distraction counter |
| `fullscreen_focus.png` | **Full Screen Focus** | Immersive OLED flip-clock canvas with minimal aesthetics |
| `statistics.png` / `stats.png` | **Analytics & Insights** | 16-week heatmap grid, time period bar charts, and focus score card |
| `calendar.png` / `history.png` | **History & Calendar** | Monthly study calendar with day-by-day session breakdown |
| `subjects.png` | **Subjects & Topics** | Color-coded subject cards, progress rings, and sub-topic lists |
| `achievements.png` | **Achievements** | Milestone badges and study awards |
| `settings.png` | **Settings & Backup** | Theme controls, reminder schedules, JSON & CSV export buttons |

---

## 📐 Screenshot Specifications
- **Resolution**: `1080 x 2400` px or `1440 x 3120` px (standard 19.5:9 or 20:9 Android display ratio)
- **Format**: PNG or WebP (lossless)
- **Frame**: Clean capture without device frame or with a subtle modern bezel
- **Color Mode**: Both Light Mode and Dark Mode captures are welcome
- **Status Bar**: Clean demo status bar (battery at 100%, Wi-Fi active, time set to 09:41 or 12:00)
