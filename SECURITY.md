# Security Policy

Security fixes and maintenance patches are actively provided for the following versions of Focentra:

| Version | Supported          | Status |
| ------- | ------------------ | ------ |
| 1.0.x   | :white_check_mark: | Active |
| < 1.0   | :x:                | EOL    |

---

## Reporting a Vulnerability

The security and privacy of Focentra users are paramount. If you believe you have discovered a security vulnerability or sensitive privacy risk in Focentra, please follow these responsible disclosure steps:

### 1. Do NOT Open a Public Issue
Please **do not** file public GitHub issues, discussions, or social media posts for suspected security vulnerabilities.

### 2. How to Report
Please report security concerns privately using one of the following methods:

- **GitHub Security Advisory (Preferred)**: Submit a private advisory report directly via [GitHub Security Advisories](https://github.com/NiloyMitra/Focentra/security/advisories/new).
- **Direct Email**: Send a detailed email to the maintainer at **niloymitra889@gmail.com** with the subject line `[SECURITY VULNERABILITY] Focentra`.

### 3. What to Include in Your Report
To help us triage and resolve the issue quickly, please include:
- A detailed description of the vulnerability.
- Steps to reproduce the issue (proof of concept, sample inputs, or test cases).
- The potential impact and attack vectors.
- Affected device configuration and Android version.
- Any suggested remediations or patches if available.

### 4. Response & Remediation Timeline
- **Initial Response**: We will acknowledge receipt of your vulnerability report within **48 hours**.
- **Assessment & Triage**: We will provide a status update and risk assessment within **5 business days**.
- **Fix & Disclosure**: Once resolved, an update will be published alongside appropriate release notes and credit to the reporter (unless anonymity is requested).

Thank you for helping keep Focentra safe and private for everyone!
